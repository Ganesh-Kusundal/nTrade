Dhan live broker requires environment variables `DHAN_CLIENT_ID`, optionally `DHAN_ACCESS_TOKEN`, and/or `DHAN_PIN` + `DHAN_TOTP_SECRET`; tokens are persisted to `DHAN_TOKEN_PATH` and TOTP attempts are rate-limited via `DHAN_COOLDOWN_PATH`. The `Dhan_Tradehull` library is optional at import time — brokers can be constructed without it, but calling Dhan-specific methods raises `ImportError` or `ConnectionError` when credentials are missing.
