The package exposes a single public surface via `__init__.py` (re-exporting domain types, events, kernel components, execution targets, sources, and runners) while the real wiring lives through three cross-cutting layers:
- **Registry layer** (`registry.py`, `factories.py`): `BrokerRegistry` lazily registers concrete brokers (paper/dhan) behind a thread-safe factory map; `SymbolMaster` flyweights instrument instances by (kind, symbol, exchange); `InstrumentFactory` delegates all object creation through this cache.
- **Facade/Session layer** (`facade.py`, `kernel/trading_session.py`): the legacy `Market` class is a thin adapter over `TradingSession`, which owns the `EventBus`, clocks, engines, and broker instance — ensuring exactly one implementation of the SDK API.
- **Event bus core** (`kernel/event_bus.py`, `events/*`): all children communicate exclusively via immutable `Event` subclasses published to a synchronous `EventBus`; engines subscribe to market/order/risk/lifecycle events and publish state-change events, giving backtest, replay, live, and simulation modes identical control flow.

Children are isolated by these contracts: brokers implement `BrokerAdapter`, market sources implement `MarketFeedSource`, execution targets implement the executor interface, and strategies subclass `Strategy`. The `runner/live_runner.py` bootstraps the full pipeline (feed → kernel → engines → execution), while `backtest/`, `replay/`, and `sim/` swap in alternative feed/clock/execution implementations without touching strategy code.
