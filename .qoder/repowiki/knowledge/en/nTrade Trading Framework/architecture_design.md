The root `ntrade` package is organized as a layered Clean Architecture where the public facade (`Market`, factories, `BrokerRegistry`) sits atop an event-centric trading kernel (`TradingKernel`, `EventBus`, `TradingClock`) which wires together pure-domain instruments, pluggable engines (market/candle/indicator/strategy/risk/order/portfolio), and interchangeable execution targets (`SimulatedExecution` vs `BrokerExecution`). Broker adapters implement a shared `BrokerAdapter` ABC so live (Dhan), paper, replay, and backtest all publish canonical events — guaranteeing zero parity across modes. The `tests/` suite validates this parity, `scripts/` provides latency benchmarks and live-validation harnesses, `agents_skills/` packages SKILL.md instructions for AI agents to invoke the Dhan-Tradehull library through the same adapter boundary, and `docs_plans/` drives agentic implementation of features using a failing-test-first discipline. A thin CLI (`check_connection.py`) reuses `ntrade.brokers.dhan_auth` for connection validation without duplicating auth logic.
