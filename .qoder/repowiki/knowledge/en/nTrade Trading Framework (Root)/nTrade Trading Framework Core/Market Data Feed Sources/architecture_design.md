The module centers on an abstract `MarketFeedSource` base class in `market_feed.py` defining the `start()`/`stop()` lifecycle and a `kernel.bus.publish(...)` interface; concrete implementations plug in without the kernel knowing their origin. Three concrete sources implement this contract: `DhanMarketFeedSource` (live websocket adapter over `dhanhq.MarketFeed`, with lazy import and injectable `feed_factory` for testing), `SimulatedFeedSource` (deterministic tick replay from a price list or OHLCV DataFrame), and `SyntheticMarketFeedSource` (1m OHLCV extrapolated to per-second ticks via `ntrade.sim.tick_simulator.synthesize_1m_ticks`). A pure function `dhan_payload_to_events` decouples wire-format parsing from the websocket layer, enabling offline unit tests of payload-to-event mapping. All sources attach to a `TradingKernel` via `attach()` and write exclusively through `self.bus.publish(...)`, preserving the zero-parity invariant. The package re-exports all public classes and the mapper through `__init__.py`.
