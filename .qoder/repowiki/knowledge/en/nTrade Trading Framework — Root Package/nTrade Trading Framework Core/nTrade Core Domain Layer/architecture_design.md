The package is organized as five sibling subpackages (instruments, market, orders, analytics) plus three top-level modules (portfolio.py, scanner.py, session.py) that compose them. Children communicate strictly through immutable value objects and typed contracts: instruments depend on market/analytics value objects, orders normalize broker responses into domain types, and the scanner/portfolio layers orchestrate the rest. There is no runtime wiring or shared registry — each package is self-contained and imported by higher-level SDK components, with __init__.py files re-exporting public APIs to form clean module boundaries.
