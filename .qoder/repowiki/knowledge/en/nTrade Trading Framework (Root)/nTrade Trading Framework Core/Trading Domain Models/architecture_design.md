The module is organized as a flat root package with four focused sub-packages plus three top-level composites:

- `instruments/` — The `Instrument` abstract base (`base.py`) is the composition root: it owns immutable state (`Quote`, `MarketDepth`, `HistoricalSeries`, `LiveStream`, indicators, signals, annotations) and exposes six *capability* objects via `@cached_property` (`market`, `trade`, `stream`, `analytics`, `derivatives`, `extension`). Concrete asset classes (`Equity`, `Index`, `ETF`, `Currency`, `Commodity`, `Bond`, `Crypto`, `Spot`, `Future`, `Option`, `SyntheticInstrument`, `OptionChain`, `Expiry`, `OptionPair`) extend this base. Broker transport is hidden behind a lazy `BrokerAdapter` injected at construction or via a factory.
- `market/` — Immutable value objects (`Quote`, `Tick`, `DepthLevel`, `MarketDepth`, `CandleSeries`, `HistoricalSeries`, `LiveStream`, `SubscriptionState`) representing point-in-time market snapshots; all are `@dataclass(frozen=True)` to enforce immutability.
- `orders/` — `Order` (frozen dataclass) plus `OrderFacade` for natural DSL entry (`stock.order.buy(75)`); `book.py` provides normalized `OrderBook`/`TradeBook` value types returned by broker adapters.
- `analytics/` — Pure-math pricing engine (`BlackScholes`, `Greeks`) in `greeks.py` and indicator utilities (`indicators.py`, `surface.py`) consumed through `AnalyticsCapability`.
- `scanner.py` — Pluggable scanner subsystem built on an abstract `Scanner` base with a `ScannerFacade` that registers built-in scanners and supports custom ones, including rate-limiting and result caching.
- Top-level `portfolio.py` (`Portfolio`, `Account`, `Position`, `Holding`) and `session.py` (`MarketState`, `SessionState`) provide composite read models and the market-state state machine.

Dependency direction is strictly inward: capabilities and higher-level composites depend on the lower-level value objects, never the reverse. Cross-package imports use `TYPE_CHECKING` guards to avoid circular imports (e.g., `Instrument` → `BrokerAdapter`, `Scanner` → `TradingSession`).
