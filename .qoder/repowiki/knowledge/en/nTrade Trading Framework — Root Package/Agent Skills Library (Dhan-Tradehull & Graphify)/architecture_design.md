Two independent skill packages live under `.agents/skills/`, each following the same layout: a top-level `SKILL.md` that serves as the agent instruction entry point, an optional `examples/` directory with runnable scripts, and a `references/` directory of topic-specific markdown guides. The `dhan-tradehull` skill documents version 3.3.2 of the Dhan-Tradehull Python wrapper around the Dhan API, covering authentication modes, market data, options chains, order placement (super orders, forever/GTT orders), portfolio management, and deployment patterns; its references are organized by domain (auth, market-data, orders, portfolio, utilities, error-log, coding-style, etc.). The `graphify` skill is a procedural playbook for running the `/graphify` CLI pipeline — detect → AST + semantic extraction → build/cluster → report — with explicit bash steps, subagent dispatch rules, cache handling, and export targets (HTML, Obsidian, Neo4j, FalkorDB, SVG, GraphML). Both skills are consumed by the host agent at runtime; there is no compiled code in this module — it is purely declarative instruction material.
