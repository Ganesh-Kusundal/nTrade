Each script is a self-contained CLI entry point that bootstraps the ntrade `TradingKernel` in either `replay` or `live` mode, wires up a feed source (`SimulatedFeedSource`, `SyntheticMarketFeedSource`, or a live websocket via `build_source`), runs the event pipeline, and prints or persists results. Dependency direction is strictly outward: scripts import from `ntrade.kernel.session.TradingKernel`, `ntrade.kernel.clock`, `ntrade.engines.strategies`, `ntrade.sources.*`, and `ntrade.runner.*`; they never import each other. Common bootstrap pattern: `sys.path.insert(0, parent)` so the package root is importable, then `TradingSession.connect('dhan')` to obtain market data before constructing the kernel. Scripts fall into three roles — benchmarks (`benchmark_latency.py` writes `.benchmarks/latency.json`), end-to-end strategy runners (`ema_cross_run.py`, `paper_gate_run.py`, `live_runner_run.py`), and live health checks (`live_read_check.py`, `live_smoke.py`).
