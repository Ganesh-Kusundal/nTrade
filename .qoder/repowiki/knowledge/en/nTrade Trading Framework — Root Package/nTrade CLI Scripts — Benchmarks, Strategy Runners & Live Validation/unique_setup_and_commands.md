All scripts expect to be run from a virtual environment with the project installed (e.g. `.venv/bin/python scripts/<script>.py`). Live scripts require a `.env` file containing Dhan credentials. Typical usage: `scripts/benchmark_latency.py [--ticks N]`, `scripts/ema_cross_run.py [SYMBOL DAYS]`, `scripts/live_runner_run.py --feed synth|live --symbol NIFTY --days N`, `scripts/paper_gate_run.py --symbol NIFTY --days 15`, and `scripts/live_read_check.py` / `scripts/live_smoke.py` for read-only Dhan validation.
