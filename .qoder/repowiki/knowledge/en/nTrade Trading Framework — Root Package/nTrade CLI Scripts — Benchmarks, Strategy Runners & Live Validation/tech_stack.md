Pure Python with `argparse` CLIs; depends on the installed `ntrade` packages (`ntrade.kernel.session.TradingKernel`, `ntrade.kernel.clock`, `ntrade.engines.strategies.EmaCrossStrategy`, `ntrade.sources.*`, `ntrade.runner.*`) plus pandas DataFrames for OHLCV history. Live connectivity uses the Dhan broker SDK accessed through `TradingSession.connect('dhan')`. Results are persisted as JSON under `.benchmarks/` or printed as structured summaries rather than log files.
