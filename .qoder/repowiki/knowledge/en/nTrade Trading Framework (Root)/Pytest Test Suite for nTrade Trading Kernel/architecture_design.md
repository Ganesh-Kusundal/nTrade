Flat pytest collection under `tests/` with one file per subsystem or scenario. Tests are organized by concern rather than strict layering: broker/unit tests (`test_brokers.py`, `test_dhan_*.py`), kernel/pipeline tests (`test_engine_pipeline.py`, `test_integration_pipeline.py`, `test_kernel_*.py`), event-bus and clock tests (`test_event_bus_*.py`), strategy-runner tests (`test_strategy_runner.py`, `test_live_runner.py`), and domain-specific tests (costs, indicators, instruments, options). Each test file is self-contained — fixtures are local helper functions (e.g. `_kernel()`, `_source()`) that construct a `TradingKernel` in `replay` or `live` mode with an injected `ReplayClock`/`LiveClock` and a `PaperBroker` or mock broker. Integration tests wire `SyntheticMarketFeedSource` to drive ticks through the full pipeline and assert on `kernel.bus.history` event types.
