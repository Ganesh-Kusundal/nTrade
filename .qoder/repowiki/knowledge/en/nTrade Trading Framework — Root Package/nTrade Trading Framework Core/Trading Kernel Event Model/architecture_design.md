The module defines a single base `Event` dataclass (frozen, kw-only) with a kernel-clock timestamp (`ts`) and auto-generated `event_id`, from which every domain-specific event inherits. Events are organized by concern into sibling modules — `market.py` (tick/quote/depth/candle/indicator), `order.py` (intent → accepted/rejected/filled/updated/timeout), `portfolio.py` (position/balance changes), `risk.py` (signal lifecycle and circuit-breaker), and `lifecycle.py` (kernel/session/runner heartbeat/feed disconnect). The package `__init__.py` re-exports all public event classes as the single import surface, so consumers subscribe to `ntrade.events.*` without importing individual files. Dependency direction is strictly one-way: each domain file imports only `base.Event`; there are no cross-domain imports between event modules, keeping the event model decoupled from the engines that produce/consume them.
