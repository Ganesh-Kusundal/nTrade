Each skill is a self-contained directory under `.agents/skills/` with a top-level `SKILL.md` that serves as the agent instruction manifest (YAML frontmatter with `name` and `description`, followed by procedural steps). Reference material lives in a sibling `references/` directory (e.g. `auth.md`, `coding-style.md`, `extraction-spec.md`) and optional runnable examples live in an `examples/` directory. The two skills are independent: `dhan-tradehull/` documents the Python Dhan-Tradehull API for algo trading, while `graphify/` documents the `/graphify` CLI pipeline for turning codebases into queryable knowledge graphs. There is no shared code — dependency direction is one-way from the agent runtime down to these markdown specifications.
