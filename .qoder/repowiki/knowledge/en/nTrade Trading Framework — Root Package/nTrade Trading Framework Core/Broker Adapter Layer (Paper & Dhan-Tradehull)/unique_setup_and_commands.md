Dhan authentication requires environment variables `DHAN_CLIENT_ID`, optionally `DHAN_ACCESS_TOKEN`, `DHAN_PIN`, `DHAN_TOTP_SECRET`, plus shared file paths `DHAN_TOKEN_PATH` and `DHAN_COOLDOWN_PATH`; the module falls back through cached token → access token → PIN+TOTP login, with a configurable `DHAN_EXPIRY_BUFFER_S` (default 900s) to proactively refresh before the 24-hour APP token expiry.
