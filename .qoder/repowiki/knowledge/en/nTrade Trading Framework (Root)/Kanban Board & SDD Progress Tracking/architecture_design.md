This module is purely metadata — no executable code. `.kanban/` holds the generated kanban CLI output: `BOARD.md` (human-readable snapshot), `board.json` (structured task list with IDs like K-001..K-019, priorities P0–P3, lanes backlog/done/planned/in_progress), `scan.json` (file index, drift detection, git log, test status, component descriptions, graphify stats), and `state.json` (per-card history, file annotations). `CONTEXT.md` is a human-written digest summarizing architecture, flows, dependencies, and recent commits. `.superpowers/sdd/progress.md` tracks feature-phase tasks (F1–G15) with pass counts and review status. All files are regenerated by external tooling (`kanban.cli`, `graphify`) and marked DO NOT EDIT; the dependency direction is one-way from source code into these artifacts via the update scripts referenced in CONTEXT.md.
