The module is a thin orchestration layer around `ntrade.events` and `ntrade.sources`, exposing four public symbols through `__init__.py`: `LiveRunner`, `build_source`, `build_paper_report`, and `measure_tick_throughput`. `live_runner.py` defines the `LiveRunner` class — the single entry point that attaches a feed to the kernel, starts both, and drives a timed loop (`step`) that calls `kernel.poll_orders()` and `kernel.sync_positions()` at configurable intervals, publishes `HeartbeatEvent`s every 30s, monitors tick-count stagnation via a watchdog (tripping `RiskHaltedEvent` after 3 missed ticks), and reacts to `RiskHaltedEvent` by activating each instrument's broker kill switch. `feeds.py` is a factory (`build_source`) that selects between `SyntheticMarketFeedSource` (synth) and `DhanMarketFeedSource` (live) based on a string flag, using lazy imports to keep synth/live decoupled. `gate.py` reconstructs equity from `PositionUpdatedEvent`/`BalanceChangedEvent` history to produce a paper-run checklist for go/no-go decisions. `bench.py` publishes synthetic `TickEvent`s back into the kernel bus to measure event-pipeline throughput. Dependency direction is one-way: runner → kernel/bus/sources; no reverse imports.
