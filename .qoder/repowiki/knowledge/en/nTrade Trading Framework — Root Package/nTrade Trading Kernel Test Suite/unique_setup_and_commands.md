Tests are run with pytest from the repository root (no special conftest is visible). Some integration tests require background threads to finish — they call `source.join(timeout=...)` after `source.start()` and use `kernel.stop(reason=...)` to shut down the kernel cleanly. Replay-mode tests set `mode="replay"` with `ReplayClock()`, while live-mode integration tests use `LiveClock()` and `PaperBroker`.
