Each engine is a single-responsibility class that subscribes to one or more kernel events via `context.bus.subscribe(...)` and publishes downstream events, forming a pure event-driven pipeline with no direct cross-engine calls. The pipeline flows: `MarketEngine` normalizes raw `TickEvent/QuoteEvent/DepthEvent` into `QuoteUpdatedEvent`; `CandleEngine` aggregates ticks into `CandleClosedEvent`; `IndicatorEngine` computes bundles and emits `IndicatorUpdatedEvent`; `StrategyEngine` fans events to user `Strategy` subclasses which emit `SignalGeneratedEvent`; `RiskEngine` screens signals into `SignalApprovedEvent`/`SignalRejectedEvent`; `OrderEngine` converts approved signals into `OrderIntentEvent` submitted to an external router; `PortfolioEngine` updates positions/cash on `OrderFilledEvent`; `PositionSyncEngine` reconciles broker-reported state back into the kernel. All engines receive a shared `context` object exposing `bus`, `instrument()`, `portfolio`, `account`, and `now()`. The `strategies.py` module provides a reusable `EmaCrossStrategy` built on the same `Strategy` base class defined in `strategy_engine.py`. Dependency direction is strictly outward: engines depend only on `ntrade.events.*` and `ntrade.domain.*` read models, never on each other.
