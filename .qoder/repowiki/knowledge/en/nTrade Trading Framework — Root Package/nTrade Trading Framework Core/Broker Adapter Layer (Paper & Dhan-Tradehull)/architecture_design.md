The module centers on `BrokerAdapter` (base.py), an ABC that declares the unified contract for market data (`get_quote`, `get_depth`, `get_historical`, `get_option_chain`), order lifecycle (`place_order`, `cancel_order`, `modify_order`, `get_order_status`), portfolio queries, and streaming subscriptions. Two concrete implementations extend it: `PaperBroker` (paper.py) — a deterministic in-memory broker seeded with random quotes and synthetic depth/history for backtesting/replay; and `DhanBroker` (dhan.py) which delegates to three focused sub-components: `DhanAuthProvider` (auth lifecycle with proactive token refresh via PIN+TOTP using `threading.Timer`), `DhanTransport` (retry/error handling around Tradehull API calls through a shared `BrokerRateGate`), and `DhanMapper` (pure data normalization from Dhan dicts/DataFrames into domain objects). The `capabilities.py` module implements a decorator-based capability registry (`@capability(name, brokers=...)`) that exposes broker-specific features dynamically through `instrument.broker.<name>()`, raising `AttributeError` when unsupported. The package exports only the public facade (`BrokerAdapter`, `BrokerExtensionFacade`, `capability`, `PaperBroker`) via `__init__.py`. Dependency direction is strictly inward: dhan.* modules depend on base.py and capabilities.py, never the reverse.
