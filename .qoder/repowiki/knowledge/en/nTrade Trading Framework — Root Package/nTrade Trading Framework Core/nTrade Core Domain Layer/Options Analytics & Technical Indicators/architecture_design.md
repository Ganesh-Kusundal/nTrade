Three focused modules under a single package:
- `greeks.py` implements the core math: a frozen `Greeks` dataclass holding delta/gamma/theta/vega/rho/iv with a `computed` sentinel pattern (`NOT_COMPUTED = None`) to distinguish zero from uncomputed values, and a `BlackScholes` static class providing `price`, `greeks`, and `implied_volatility` (bisection solver). No external dependencies beyond `math`.
- `indicators.py` provides pure functions operating on pandas OHLCV DataFrames (RSI, ATR, SMA, EMA, VWAP, SuperTrend, Heikin-Ashi, Renko bricks) and a `compute_bundle` aggregator that safely captures each indicator's latest value into a flat dict, logging failures instead of swallowing them.
- `surface.py` defines `IVSurface` and `GreeksTable` wrapper classes that present a domain-typed API over raw `pd.DataFrame`s while delegating unknown attributes via `__getattr__` and exposing a `to_dataframe()` escape hatch — mirroring the `HistoricalSeries` pattern used elsewhere in the domain layer.
- The package re-exports only `Greeks` and `BlackScholes` through `__init__.py`, keeping the public surface minimal. Dependency direction is one-way: surface wraps DataFrames produced by higher layers; greeks has no imports outside stdlib; indicators depends only on pandas.
