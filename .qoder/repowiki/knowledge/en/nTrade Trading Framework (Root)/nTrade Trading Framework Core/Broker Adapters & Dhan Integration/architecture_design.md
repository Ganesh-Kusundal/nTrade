The module centers on `base.BrokerAdapter`, an abstract base class that defines the uniform contract (connect/disconnect, get_quote/get_depth/get_historical, place_order and lifecycle methods, subscribe/unsubscribe streaming) that all broker implementations must satisfy. Two concrete adapters implement this contract: `PaperBroker` (in-memory, deterministic, used for tests/backtests/replays) and `DhanBroker` (live broker wrapping the external `Dhan_Tradehull` library). The Dhan implementation is decomposed into four focused components following a provider pattern: `dhan_auth_provider.DhanAuthProvider` manages the authentication lifecycle, `dhan_auth.get_tradehull` handles credential resolution (shared token store → env access token → PIN+TOTP fallback), `dhan_transport.DhanTransport` wraps raw Tradehull calls with retry/error handling, and `dhan_mapper.DhanMapper` provides pure static normalization functions converting raw API responses into domain objects. Cross-broker extensions are exposed through `capabilities.py`'s `BrokerExtensionFacade` and `@capability` decorator, allowing broker-specific features (e.g., depth20, margin_calculator, kill_switch) to be registered and dynamically dispatched via `instrument.broker.<name>()` without polluting the base adapter API. The package's `__init__.py` re-exports only the public surface: `BrokerAdapter`, `BrokerExtensionFacade`, `capability`, and `PaperBroker`.
