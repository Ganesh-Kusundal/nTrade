The package is organized as layered subsystems communicating exclusively through immutable events on the kernel's EventBus: sources publish market events, engines consume/produce them (candle, indicator, risk, order, portfolio), and execution bridges orders to broker adapters or simulators. The flat `__init__.py` re-exports the entire public SDK surface, while `factories.py` and `registry.py` provide flyweight instrument caching (`SymbolMaster`) and broker factory registration (`BrokerRegistry`) shared across all layers. Each subsystem (kernel, events, domain, engines, execution, brokers, sources, backtest, runner, replay, storage) is an isolated Python package; cross-cutting wiring happens at import time via the flat API and lazy default registrations in `_ensure_default_brokers`. Zero parity between paper/live/backtest/replay is enforced by the common Event model and interchangeable source/execution contracts rather than conditional logic inside strategies.
