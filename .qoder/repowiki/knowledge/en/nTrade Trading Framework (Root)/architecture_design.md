The root is the ntrade Python package defined by pyproject.toml (setuptools, requires-python>=3.10) whose single dependency surface is pandas, numpy, python-dotenv, and Dhan-Tradehull. ARCHITECTURE.md documents the Clean Architecture split: a public facade + factories layer, an event-centric TradingKernel with interchangeable live/replay/backtest modes, a pure-Python domain layer of rich Instrument objects, a BrokerAdapter abstraction over PaperBroker/DhanBroker, and infrastructure for transport/persistence/replay. Children are wired together through canonical frozen events in `events/` and the EventBus — brokers, replay engine, and backtest simulator all publish the same Tick/Quote/Depth events so strategies see identical streams regardless of mode (zero parity). The `scripts/` entrypoints exercise this stack end-to-end, `tests/` validates it via pytest, `agents_skills/` provides SKILL.md docs for AI agents to invoke the Dhan-Tradehull library, and `benchmarks_and_cache/` holds generated kanban/SDD metadata. `check_connection.py` is a thin CLI that authenticates against Dhan Tradehull via `ntrade.brokers.dhan_auth` without placing orders.
