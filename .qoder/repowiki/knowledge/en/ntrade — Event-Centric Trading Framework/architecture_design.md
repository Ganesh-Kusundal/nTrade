The package follows Clean Architecture with strict dependency direction: `domain/` (pure Python instruments, quotes, orders, analytics) imports nothing from broker or infra layers; `brokers/` implements `BrokerAdapter` ABCs (PaperBroker, DhanBroker) that normalize wire formats into domain objects; `kernel/` (`TradingKernel`, `ResilientKernel`, `StrategyRunner`, `EventBus`, `TradingClock`) wires engines via canonical events; `engines/` holds market/candle/indicator/risk/order/portfolio engines; `execution/` provides `ExecutionRouter` dispatching to `SimulatedExecution` or `BrokerExecution`; `sources/` abstracts data producers as `MarketFeedSource` subclasses (Dhan, synthetic, simulated); `backtest/` and `replay/` plug deterministic event streams into the same kernel. The public surface is re-exported through `ntrade/__init__.py` and `facade.py` (`Market`), with `factories.py` (`InstrumentFactory`, `OptionFactory`) and `registry.py` (`SymbolMaster` flyweight, `BrokerRegistry`) handling creation. Broker-specific capabilities are registered via a `@capability` decorator and resolved at call time through `BrokerExtensionFacade`, keeping base instruments broker-agnostic. Zero parity is enforced: the same event stream through `TradingKernel(mode=...)` produces identical fills in live, replay, and backtest.
