Each skill is self-contained — no build step. For dhan-tradehull, agents must `pip install --pre dhanhq && pip install Dhan-Tradehull` before generating trading code. For graphify, the skill itself contains the full bootstrap script that auto-detects the Python interpreter (uv tool, pipx, shebang, or python3 fallback), installs `graphifyy` if missing, and writes `graphify-out/.graphify_python` for subsequent steps. The graphify workflow expects a `graphify-out/` output directory created in the project root where commands are run.
