- Broker implementations subclass `BrokerAdapter` and override only the abstract methods (`connect`, `get_quote`, `get_historical`, `place_order`), relying on the base class for shared state like `_subscriptions`, `_connected`, and timestamp resolution via `_ts()`.
- Optional/advanced broker features are declared as capabilities using the `@capability(name, brokers=(...))` decorator, which registers them globally and exposes them through `instrument.broker.<name>()` with fail-fast `AttributeError` when unsupported by the current broker.
- External library dependencies (notably `Dhan_Tradehull`) are imported lazily inside try/except blocks so the module remains importable without the optional dependency, with explicit `ImportError` raised only when the feature is actually invoked.
- Data normalization helpers use sentinel functions (`_first_str`, `_first_int`, `_first_float`, `_f`) that accept multiple column name variants and return safe defaults, keeping raw API field names isolated from callers.
- Timestamps flow through an injectable clock (`set_clock`) with priority order: explicit `now` parameter > injected clock > wall clock, ensuring zero-parity replay determinism across paper and live brokers.
- Network calls follow a retry-then-fail pattern: non-critical endpoints return empty/zero on failure, while critical paths (LTP, order placement) raise descriptive exceptions rather than silently collapsing to zeros.
