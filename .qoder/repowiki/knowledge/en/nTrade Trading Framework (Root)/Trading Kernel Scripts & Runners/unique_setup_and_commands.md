All scripts expect to be run from within the project's virtual environment: `.venv/bin/python scripts/<script>.py`. Several require a `.env` file with Dhan credentials. Typical invocations include `scripts/benchmark_latency.py [--ticks 10000]`, `scripts/ema_cross_run.py [SYMBOL=NIFTY] [DAYS=15]`, `scripts/live_runner_run.py --feed {synth|live} --symbol NIFTY --days 2`, and `scripts/paper_gate_run.py --symbol NIFTY --days 15`.
